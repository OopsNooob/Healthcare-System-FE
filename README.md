# Healthcare System Frontend

This is a comprehensive frontend monorepo for the Healthcare System, containing both web and mobile applications to seamlessly connect patients with healthcare professionals.

## Architecture

This project is built using a modern Turborepo monorepo architecture:

- `apps/web-client`: The Next.js web application for comprehensive healthcare management.
- `apps/mobile`: The Expo/React Native mobile application for on-the-go health tracking and consultations.
- `packages/ui`: Shared UI components for consistency across platforms.
- `packages/config`: Shared configurations for ESLint, TypeScript, and Tailwind CSS.

## Features

- **Multi-platform Access:** Seamlessly use the system via Web or Mobile apps.
- **AI-Powered:** Includes AI health metrics summarization and interactive health assistants.
- **Real-time Consultation:** Integrated WebRTC video calls and live chat between doctors and patients.
- **Premium Subscription:** Integrated payments (VNPAY mockup) for priority queueing and unlimited AI access.
- **Smart Queue System:** Real-time appointment queue tracking.
